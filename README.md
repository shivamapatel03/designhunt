# DesignHub 🎨
**Master UI/UX design through an interactive, gamified, and community-driven platform.**

DesignHub is a comprehensive learning ecosystem designed to take aspiring designers from fundamentals to advanced industry techniques. It combines structured learning paths with interactive playgrounds and community engagement.

---

## ✨ Key Features

### 🧠 Theory Hub
Master the fundamental principles of design through interactive, visual guides:
- **Color Theory**: Contrast checkers, harmony rules, and psychology.
- **Typography**: Hierarchy, fluid scaling, and readability calculators.
- **Motion & Animation**: Interactive Bezier editors and easing curve visualizers.
- **UX Laws**: Deep dives into Fitts's Law, Hick's Law, and cognitive psychology in design.
- **Layout & Grids**: Mastery of the 12-column system, spacing, and vertical rhythm.

### 🛤️ Advanced Learning Paths
- **Structured Curriculum**: Progressive levels and sections covering specialized topics.
- **Gamified Progression**: Earn XP, maintain daily streaks, and achieve ranks.
- **Real-time Feedback**: Instant quiz results and progress persistence.

### 🤝 Community & Critique
- **Idea Sharing**: A space to showcase creative concepts and get inspired.
- **Design Critique**: Peer-to-peer feedback loop to improve design work.

### 🛠️ Specialized Dashboards
- **Student Dashboard**: Personalized learning progress and stats.
- **Tutor Dashboard**: Manage course content and student engagement.
- **Admin Panel**: High-level platform oversight and content moderation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd "new look"
   ```

2. **Frontend Setup:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   *Accessible at `http://localhost:3000`*

3. **Backend Setup:**
   ```bash
   cd ../backend
   npm install
   npm run dev
   ```
   *Accessible at `http://localhost:5000`*
